How to read this

Each team's projected rotation comes from the depth charts. For every game, each rotation player who did not play is tagged with nba.com's reason (injury/illness, rest, coach's decision, G League, ...). Only injuries count toward the injury numbers below; other absences are shown separately.

Cost is how much worse the team is, in points per 100 possessions, with the missing players' projected minutes going to a replacement-level player instead (NERD + DARKO ratings), the same cost the power ratings use. Missing a star for a game costs far more than missing a bench player. Wins lost converts each game's cost to win probability (about 0.033 wins per point of expected margin) and adds them up.

Some nba.com box scores list a player as inactive without a reason. For rotation players that is almost always an injury, so it counts as one by default (toggle below).
