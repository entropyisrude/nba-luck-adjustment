Lineup Validation

First-pass external audit for the new lineup engine. This page checks whether our 5-man unit table is at least surfacing real starting groups from Basketball-Reference for the current season.

This is intentionally a floor test, not the final word. It validates lineup detection presence and basic game coverage. It does not yet validate exact per-game ORtg/DRtg or minute totals against a full external lineup feed.
